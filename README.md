# Data Mining

Repository ini berisi progress mata kuliah Data Mining berdasarkan course di Coursera.

## Course 1

Pada course 1, saya menonton video di Coursera tentang pengantar machine learning dan deep learning, serta tutorial cara mengambil data, kemudian mengerjakan praktikum data cleaning menggunakan dataset Ames Housing.

## Course 2

Pada course 2, saya mempelajari supervised learning, meliputi regresi linear dan pemisahan data (train-test split), regresi polinomial, validasi silang (cross validation), serta teknik regularisasi Ridge, LASSO, dan elastic net. Setiap latihan dikerjakan dalam notebook terpisah di folder course-02.

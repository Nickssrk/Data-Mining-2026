# Data Mining

Repository ini berisi progress mata kuliah Data Mining berdasarkan course di Coursera.

## Course 1

Pada course 1, saya menonton video di Coursera tentang pengantar machine learning dan deep learning, serta tutorial cara mengambil data, kemudian mengerjakan praktikum data cleaning menggunakan dataset Ames Housing.

## Course 2

Pada course 2, saya mempelajari supervised learning, meliputi regresi linear dan pemisahan data (train-test split), regresi polinomial, validasi silang (cross validation), serta teknik regularisasi Ridge, LASSO, dan elastic net. Setiap latihan dikerjakan dalam notebook terpisah di folder Course 2, dan ditutup dengan final assignment berupa analisis regresi harga rumah menggunakan dataset Ames Housing.

## Course 3

Pada course 3, saya mempelajari supervised learning untuk klasifikasi, meliputi regresi logistik, K-nearest neighbors, decision tree, support vector machine, penanganan data yang tidak seimbang, metode ensemble (AdaBoost dan stacking), serta teknik penjelasan model seperti permutation importance, partial dependence plot, dan LIME. Setiap latihan dikerjakan dalam notebook terpisah di folder Course 3, dan ditutup dengan final assignment berupa analisis klasifikasi untuk mengidentifikasi rumah premium menggunakan dataset Ames Housing.
